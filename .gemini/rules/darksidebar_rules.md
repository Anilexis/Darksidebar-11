# Правила проекта Darksidebar-11

## Обязательный регламент и архитектура
1. **Семантическое версионирование (SemVer):** При любых исправлениях багов или доработках обязательно поднимать версию (PATCH: `1.0.x`, MINOR: `1.x.0`, MAJOR: `x.0.0`).
2. **Сборка пакета:** Запускать `./build-package.ps1 -Version "<ВЕРСИЯ>"`, формирующий `dist/Darksidebar-11-v<ВЕРСИЯ>.rmskin`.
3. **Хеш Scoop:** Вычислять точный SHA256 хеш файла `.rmskin` и обновлять `bucket/darksidebar-11.json` (`version`, `url`, `hash`). После сборки на GitHub Actions сверять и обновлять хеш артефакта релиза.
4. **Git & GitHub:** Коммитить изменения, ставить тег `v<ВЕРСИЯ>`, пушить ветку `main` и тег на GitHub (`git push origin main; git push origin v<ВЕРСИЯ>`).
5. **Строгая деперсонализация:** Репозиторий и публичные пакеты `.rmskin` НЕ ДОЛЖНЫ содержать личные данные разработчика (никаких дисков D, E, G, T, W, никакого монитора SyncMaster/DISPLAY2, никакого города Тюмень). В репозитории лежат нейтральные шаблоны (Primary дисплей, 1 диск C:, London дефолт, `FirstRunDone=0`).
6. **Персональные настройки пользователя:** Хранятся ТОЛЬКО локально в `%USERPROFILE%\Documents\Rainmeter\Skins\Darksidebar-11\@Resources\Settings.inc` и личных кэшах, и никогда не пушатся в Git.
7. **Кодировка:** Все файлы `.ini` и `.inc` скина сохранять СТРОГО в **Windows-1251 (CP1251)**. Запрещено использовать UTF-8.
8. **Защита настроек при обновлении (Scoop и .rmskin):** Существующий `Settings.inc` и дисковая топология пользователя не должны перезаписываться при обновлениях. Все настройки зеркалируются в независимое персистентное хранилище `%APPDATA%\Rainmeter\Darksidebar11-Config\`. При обновлениях или повторных установках `first-run.ps1` и установщик Scoop восстанавливают город, координаты, монитор и диски из персистентного хранилища. Деинсталлятор Scoop ни при каких обстоятельствах не удаляет рабочую папку скина пользователя (`Remove-Item` запрещен).
